Escalera de ayudas — Katas capítulos 1–5

Regla de la escalera: intenta primero el kata sin ayuda. Solo si llevas 15 minutos atascado bajas un peldaño: Nivel 1 (pista de clase) → Nivel 2 (pseudocódigo) → Nivel 3 (esqueleto con huecos). Nunca saltes al Nivel 3 sin haber leído el Nivel 1. Los huecos se muestran como ___: rellénalos tú.

1 · Beginner Series #2 Clock 8 kyu · cap. 1–2

Nivel 1 — Pista de clase
No hay ningún if: es aritmética pura. Convierte todo a segundos y luego a milisegundos. 1 hora = 3600 s, 1 minuto = 60 s, 1 segundo = 1000 ms. Recuerda: el kata pide devolver (return), no imprimir.
Nivel 2 — Pseudocódigo
función past(h, m, s):
    segundos_totales ← h × 3600  +  m × 60  +  s
    devolver segundos_totales × 1000
Nivel 3 — Esqueleto con huecos

    return (h * ___ + m * ___ + s) * ___

función repeat_str(n, s):
    devolver s repetido n veces      ← s * n

3 · Find Nearest square number 8 kyu · cap. 1–2

Nivel 1 — Pista de clase
La raíz cuadrada de n casi nunca es entera. math.sqrt(n) te da el número cuyo cuadrado sería n; round() elige el entero más cercano (baja o sube según cuál cuadre mejor). Después eleva al cuadrado ese entero.
Nivel 2 — Pseudocódigo
import math
función nearest_sq(n):
    r ← raíz cuadrada de n
    k ← entero más cercano a r      ← round(r)
    devolver k al cuadrado           ← k ** 2
Nivel 3 — Esqueleto con huecos
import math
def nearest_sq(n):
    k = ___(math.sqrt(n))
    return k ___ 2

6 · Exclusive "or" (xor) 8 kyu · cap. 5

Nivel 1 — Pista de clase
«O exclusiva» = uno u otro, pero no ambos. Solo es True cuando los dos valores son distintos. Piensa qué operador de comparación compara «distinto». También puedes construirlo con and/or/not.
Nivel 2 — Pseudocódigo
función xor(a, b):
    si a y b son distintos → True
    si son iguales        → False
    forma corta: devolver a != b
Nivel 3 — Esqueleto con huecos
def xor(a, b):
    return a ___ b

7 · Calculate BMI 8 kyu · cap. 1, 5

Nivel 1 — Pista de clase
Primero calcula bmi = peso / altura ** 2. Después encadena if / elif / else de menor a mayor (18.5, luego 25, luego 30): cada elif solo se evalúa si el anterior ya falló, así no necesitas rangos por los dos lados.
Nivel 2 — Pseudocódigo
función bmi(peso, altura):
    b ← peso / altura²
    si b <= 18.5 → "Underweight"
    si no, b <= 25  → "Normal"
    si no, b <= 30  → "Overweight"
    si no         → "Obese"
Nivel 3 — Esqueleto con huecos

8 · Is this a triangle? 7 kyu · cap. 5

Nivel 1 — Pista de clase
Desigualdad triangular: cada lado debe ser menor que la suma de los otros dos. Ojo: el kata exige triángulos con área > 0, así que la comparación es estricta (>, no >=). 1,2,3 no vale. Son tres comprobaciones unidas con and.
Nivel 2 — Pseudocódigo
función is_triangle(a, b, c):
    devolver (a + b > c)  y  (a + c > b)  y  (b + c > a)
    las TRES a la vez
Nivel 3 — Esqueleto con huecos
def is_triangle(a, b, c):
    return a + b ___ c ___ a + c > b ___ b + c > a

9 · Rock Paper Scissors! 8 kyu · cap. 5

Nivel 1 — Pista de clase
Solo hay 3 casos en los que gana el jugador 1: rock>scissors, scissors>paper, paper>rock. Comprueba primero el empate (p1 == p2), luego los 3 casos ganadores (un or de tres condiciones), y todo lo demás es victoria del 2. Las cadenas se comparan con == y son en inglés.
Nivel 2 — Pseudocódigo
función rps(p1, p2):
    si p1 == p2              → "Draw!"
    si (p1,p2) es uno de los
       3 pares ganadores     → "Player 1 won!"
    si no                    → "Player 2 won!"

10 · Grasshopper - Summation 8 kyu · cap. 5

Nivel 1 — Pista de clase
Hay tres caminos: (a) recursión — caso base num == 1 → 1 y caso general num + lo_mismo(num-1); (b) un bucle que acumula; (c) la fórmula directa n*(n+1)//2. Si tu profe pide practicar recursión, usa la (a) obligatoriamente.
Nivel 2 — Pseudocódigo
recursiva:
  si num == 1 → devolver 1            ← caso base
  si no → devolver num + summation(num-1)

fórmula:
  devolver num * (num + 1) // 2
