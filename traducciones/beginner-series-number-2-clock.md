El reloj marca `h` horas, `m` minutos y `s` segundos desde medianoche.

Tu tarea es escribir una función que devuelva el tiempo transcurrido desde medianoche **en milisegundos**.

## Ejemplo

```
h = 0
m = 1
s = 1

resultado = 61000
```

Restricciones de entrada:

* `0 <= h <= 23`
* `0 <= m <= 59`
* `0 <= s <= 59`
