Implementa una función que acepte 3 valores enteros `a`, `b`, `c`. La función debe devolver `true` si se puede construir un triángulo con lados de esas longitudes, y `false` en cualquier otro caso.

(En este kata, todos los triángulos deben tener superficie mayor que 0 para ser aceptados; un triángulo degenerado como 1, 2, 3 **no** vale.)

Ejemplos:
```
Entrada -> Salida
1,2,2   -> true
4,2,3   -> true
2,2,2   -> true
1,2,3   -> false
-5,1,3  -> false
0,2,3   -> false
1,2,9   -> false
```
